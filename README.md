# Seraph

A collection of practical terminal applications, Raspberry Pi projects, and
workshop utilities developed for the Seraph Linux system.

## Projects

### Bullet Lube Calculator

A dependency-free terminal utility for calculating percentage-based bullet
lube recipes by weight.

Features include:

- Pounds, ounces, kilograms, and grams
- Any number of recipe ingredients
- Saved reusable recipes
- Batch-size recalculation
- Plain-text recipe export
- Linux, macOS, and Windows support
