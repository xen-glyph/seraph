# Changelog

## 2.0.0 — 2026-08-07

- Renamed the project to **Cast Bullet Workshop Calculator**.
- Retained the complete percentage-based Bullet Lube Calculator.
- Added built-in cast-bullet alloy recipes:
  - Pure Lead
  - 40:1, 30:1, 25:1, 20:1, and 16:1 Lead/Tin
  - Lyman No. 2
  - Hardball
  - Linotype 84/4/12
- Added exact traditional parts-ratio calculations instead of relying on
  rounded commercial labels.
- Added custom alloy recipes and persistent storage.
- Added a built-in and custom source-alloy library.
- Added exact two- and three-source mass-balance calculations for Pb/Sn/Sb.
- Added automatic searches for valid two- and three-source blend solutions.
- Added 76-column text export to every calculation result.
- Added generic CUPS printing with configurable queue and top spacing.
- Defaulted printed reports to two leading blank lines.
- Added automatic migration of recipes from earlier Bullet Lube Calculator
  installations.
- Added Linux/macOS and Windows installers and uninstallers.
- Added tests, examples, source notes, and expanded documentation.
