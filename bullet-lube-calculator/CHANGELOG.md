# Changelog

All notable changes to Bullet Lube Calculator are documented here.

## 1.2.0 - 2026-08-07

- Prepared the program for public sharing.
- Removed printer-specific behavior and configuration.
- Added export of calculated batch sheets as plain-text files.
- Added cross-platform per-user recipe storage.
- Added `--version` and `--no-color` options.
- Added Linux/macOS install and uninstall scripts.
- Added automated calculation and formatting tests.

## 1.1.0

- Added colored terminal menus and 76-column report formatting.
- Added reusable saved recipes and batch-size recalculation.

## 1.0.0

- Initial percentage-based ingredient calculator.
